# TripMate AI

Create a modern, premium, fully responsive AI Trip Planning website called "TripMate AI".

The website should have a futuristic and professional travel startup design. Use a clean layout, smooth animations, glassmorphism effects, beautiful travel imagery, rounded cards, gradients, and a premium user experience.

MAIN WEBSITE FEATURES:

1. NAVIGATION BAR

- Logo: 🌍 TripMate AI

- Home

- Explore

- My Trips

- About

- Login button

- Sticky navigation bar

2. HERO SECTION

Create a beautiful full-screen travel hero section with:

- Large heading: "Plan Your Perfect Journey"

- Subtitle: "Let AI create the perfect trip based on your budget, interests, and travel duration."

- Animated background

- Travel-related visuals

- "Plan My Trip" call-to-action button

3. TRIP PLANNER FORM

Include the following fields:

- Starting location

- Destination

- Travel date

- Number of days

- Number of travelers

- Total budget in ₹

- Travel interests:

  Adventure

  Nature

  Food

  Shopping

  Relaxation

  Culture

- Transportation preference:

  Car

  Bus

  Train

  Flight

- A large button: "✨ Generate My Trip"

4. AI TRIP RESULT PAGE

After submitting the form, generate a beautiful trip itinerary.

Show:

- Trip summary

- Starting location

- Destination

- Number of days

- Number of travelers

- Budget

- Selected interests

Create a separate card for every day.

Example:

DAY 1

🌅 Morning: Visit a popular attraction

🍽️ Afternoon: Try recommended local food

📸 Evening: Visit another famous location

🌙 Night: Hotel/rest suggestion

DAY 2

Generate different activities and places.

5. BUDGET BREAKDOWN

Display the budget using cards or a chart:

🚗 Transportation – 30%

🏨 Accommodation – 35%

🍔 Food – 20%

🎯 Activities – 15%

Show the total amount in Indian Rupees.

6. EXPLORE DESTINATIONS SECTION

Create attractive destination cards with images for:

- Ooty

- Kodaikanal

- Goa

- Manali

- Kerala

- Jaipur

- Mumbai

- Delhi

Each card should show:

- Destination image

- Destination name

- Short description

- "Explore" button

7. EXTRA FEATURES

Add:

- Dark mode and light mode

- Smooth scrolling

- Loading animation when generating the trip

- Save trip button

- Share trip button

- Favorite destinations

- Packing checklist

- Travel tips section

- Mobile responsive design

8. DESIGN STYLE

Use:

- Modern premium UI

- Glassmorphism

- Smooth hover animations

- Rounded corners

- Beautiful shadows

- Gradient buttons

- Professional typography

- Travel-themed icons

- Fully responsive for mobile, tablet, and desktop

9. TECHNOLOGY

Build using:

- HTML

- CSS

- JavaScript

Keep the code organized into:

- index.html

- style.css

- script.js

Make all buttons functional.

The trip planner should validate empty fields.

When the user clicks "Generate My Trip":

- Show a loading animation saying "AI is planning your perfect trip..."

- Then display a dynamically generated trip itinerary based on the destination, number of days, budget, and interests.

Use realistic sample destination data for the demo.

The final website should look like a professional AI travel startup, not a basic student project.
